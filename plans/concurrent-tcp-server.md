## 项目目标

将外部请求接入线程池执行确定性任务，完整理解“请求 → 消息解析 → 排队 → 执行 → 响应”。echo 可作第一步连通练习，但最终需明确任务与响应关联。

## 待创建任务（尚未创建到新仓库）

1. W6：定义最小协议并处理一个请求。明确消息边界、长度上限、部分读写、EOF 和错误；记录正常请求与响应示例。

4. W7：集成测试、压测和收尾。包含分片/合并消息、断连、过载和停止测试；记录吞吐、延迟分位数、错误率、工作负载与原始数据。样本不足不夸大 p99。

## 范围控制

先用简单 TCP，必要时使用成熟库并记录取舍。epoll 先理解就绪通知，不要求手写复杂 Reactor/HTTP 框架。两周到期保留最小可用版本，进入模型阶段。

线程池当前的单外部调用者 stop 约定仍适用；stop 本身不会解除网络 recv 阻塞。任务队列无界问题需在服务接入时通过明确容量方案处理。
