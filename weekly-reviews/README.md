## 使用规则

每周复制 TEMPLATE.md，文件名例如 `2026-10-17-W06.md`，填实际发生的六项；周中检查加 `checkpoint`，不冒充结周。
补写标明覆盖日期和实际补写日期。没有数据就写未记录，不按30h预算填工时。提交日期不一定等于学习日期，不将跨周成果提前记账。
本科/课程、算法等未在本次资料出现的活动，不推断为没做，也不虚构完成量。
