## 使用说明

文件统一使用 `YYYY-MM-DD-WNN-type.md`；周复盘用 review，阶段记录用 checkpoint，归档核验用 verification。模板有对应字段，不把周中记录写成整周完成。
旧记录的结论属于当时状态；现在做什么看 [now.md](../now.md)。完整代码/日志在子仓库，总控保留摘要和链接。实际工时未知就写未记录，不用预算或聊天轮数倒推。
